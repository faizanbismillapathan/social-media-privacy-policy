# Privacy Policy

**Last Updated:** October 14, 2026

## 1. Introduction

This Privacy Policy explains how the Social Media Management System handles information when you use the application.

The application is a personal tool designed to help manage social media activities through official platform APIs.

## 2. Information We Access

Depending on the features you enable, the application may access Pinterest account information, boards, Pins, and related analytics through the official Pinterest API.

The application accesses only the information required for its enabled features and authorized permissions.

## 3. How Information Is Used

Information accessed through Pinterest is used only to provide the application's features, such as publishing Pins, managing content, and viewing available analytics.

We do not sell personal information or use it for unrelated purposes.

## 4. API Credentials and Data Storage

The application is designed for local use on the user's computer. Pinterest API credentials and tokens should be stored locally and protected from unauthorized access.

The application does not intentionally send this information to third parties, except as necessary to communicate with Pinterest or other services explicitly enabled by the user.

## 5. Third-Party Services

Pinterest API usage is subject to Pinterest's applicable terms, policies, and privacy practices.

The application does not control how Pinterest processes information on its platform.

## 6. Data Retention and Deletion

Users can remove locally stored application data and disconnect their Pinterest account through the available account authorization or revocation options.

Information retained by Pinterest remains subject to Pinterest's own policies.

## 7. Security

Reasonable measures should be taken to protect stored credentials and personal information. No method of electronic storage or transmission is completely secure.

## 8. Changes to This Policy

This Privacy Policy may be updated when the application's features or data practices change. The latest version will be published on this page.
